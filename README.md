# 📈 MarketInsight — Agentic AI Market Intelligence System

An autonomous AI agent system that fetches real-time market news, analyzes sentiment, and generates professional business intelligence reports — fully automated with zero manual intervention.

---

## 🎯 What It Does

You type one company name → The system automatically:
1. Fetches latest news headlines from Google News
2. Analyzes market sentiment using AI (Positive/Negative/Neutral)
3. Generates a complete professional investment report
4. Saves the report as a file automatically

## 🛠️ Tech Stack

- **Python** — Core programming language
- **OpenRouter API** — Free LLM API gateway
- **LLaMA / Mistral** — AI models for analysis
- **BeautifulSoup4** — Web scraping for news
- **Requests** — HTTP requests to fetch web pages
- **python-dotenv** — Secure API key management
